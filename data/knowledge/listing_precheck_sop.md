# Listing 上架前合规预审 SOP

本 SOP 适用于美国、欧盟、日本站的标题、五点描述、详情页、A+ 和广告文案。预审是上架流程的固定环节，未通过不得提交。

## 触发时机

- 新品首次上架。
- 老品修改标题、五点、详情页、A+ 或主图。
- 新增站点、语言或品类。
- 收到绩效通知、侵权投诉、 Listing 被抑制后。
- 大促前批量检查。

## 输入材料

1. 站点、语言、ASIN（新品可为空）。
2. 完整文案：标题、五点、描述、A+ 文本。
3. 产品分类、材质、适用人群。
4. 认证/检测/商标/授权文件（如有功效、认证、品牌词）。
5. 促销信息与活动时间（如涉及价格）。

## 处理流程

1. **文本清洗**：统一全半角、去 HTML、保留原文语义；不要为了通过检测删词后改变原意。
2. **规则检测**：按站点词库检测绝对化、功效、侵权、安全、价格、环保等类别。
3. **风险分级**：
   - 高危：直接拦截，禁止上架。
   - 模糊：LLM 结合上下文复核并打标，仍无法确定则转人工。
   - 低风险/未命中：进入知识库依据核验。
4. **知识库核验**：检索站点政策、品类要求、历史案例，形成可追溯引用。
5. **人工复核**：法律定性、商标/专利、认证真伪、监管分类必须人工确认。
6. **输出结论**：通过 / 需修改 / 拦截 / 转人工，附规则 ID、原文片段、修改建议、引用来源。
7. **复审**：修改后重新执行完整检测，不能只检查被删词。
8. **留档**：结论、证据、工具调用和模型打标保存至少 180 天。

## 风险判定口径

| 等级 | 判定 | 处理 |
| --- | --- | --- |
| 高危 | 命中 block 规则，或高风险类别无法提供证据 | 直接拦截，禁止上架 |
| 中危 | 命中 review 规则，或语义模糊 | LLM 复核 + 人工确认 |
| 低危 | 仅低风险提示，有可核验依据 | 修改后可放行，留档 |
| 无依据 | 规则未命中但知识库无可靠依据 | 不得直接放行，转人工 |

风控原则是“宁可多复核，不可漏放”。模型不能覆盖规则引擎的拦截结论。

## 输出字段

- `decision`：passed / review / blocked
- `risk_score`：0–99
- `matches`：规则 ID、命中词、原文位置、建议
- `citations`：知识库片段与来源
- `handoff`：是否需要人工、原因、优先级
- `guardrails`：是否用原文检测、引用是否有效、依据是否充分

## 时效与责任

- 普通新品：4 小时内完成首轮。
- 大促批量：提前 3 个工作日。
- 高危/侵权投诉：立即升级合规负责人。
- 预审人对结论负责；模型和规则引擎只提供辅助证据。

## 常见退回原因

- 只删了命中词，但保留了同一功效语义。
- 用拼音、谐音、空格、符号规避检测。
- 认证编号缺失或与产品型号不一致。
- 兼容性描述暗示品牌授权。
- 引用知识库但未核对站点/版本。
