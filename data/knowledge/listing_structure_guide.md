# Listing 结构与文案规范

合规预审不仅看敏感词，也看结构是否完整、信息是否一致。以下为美国/欧盟/日本站通用规范。

## 标题

- 建议结构：品牌 + 核心品类 + 关键属性 + 适用场景 + 规格。
- 美国站不超过 200 字符；日本站建议 50–80 个字符，避免关键词堆砌。
- 不得出现促销语、价格、运费、主观排名、竞品品牌。
- 型号、数量、颜色必须与变体和图片一致。
- 首字母大写，避免全大写和特殊符号。

示例：

> Anker USB-C to USB-C Cable 1m, 100W Fast Charging Nylon Braided for iPhone 15, MacBook Air, Samsung S24

注意：示例中的品牌需为自有或已授权；`for iPhone` 属于兼容性描述。

## 五点描述

- 每点聚焦一个卖点：材料、性能、使用场景、兼容性、售后。
- 先写用户收益，再写支撑证据。
- 避免绝对化、医疗功效、虚假认证。
- 兼容性写法：`Compatible with ...`，不要写 `official`。
- 售后写 `30-day return policy`，不要写 `100% satisfaction guaranteed`。

## 详情页

- 补充尺寸、材质、包装清单、使用说明、警告语。
- 不得出现与标题/五点矛盾的信息。
- 日本站需要日语说明；欧盟需要销售国语言。
- 涉及电池、磁性、儿童用品时，必须写安全警告。

## A+ 内容

- 图片、对比表、品牌故事都受广告宣称规则约束。
- 不得使用竞品商标、角色形象、未授权字体/图片。
- 对比表只能与自家产品对比，或使用可验证的通用参数。
- 认证标志必须有授权和证书编号。

## 图片

- 主图白底，产品占画面 85% 左右。
- 不得添加水印、边框、促销文字、平台 UI。
- 场景图不得暗示未包含的配件。
- CE、PSE、UL 等标志不能 PS 到产品上。

## 关键词与后台搜索词

- 不堆砌竞品品牌、错拼词、无关热搜词。
- 不包含价格、促销、主观评价。
- 日本站注意全半角、片假名/平假名/汉字变体。
- 后台搜索词同样可能构成商标侵权。

## 多语言

- 不要用机器翻译直接上架；功效词和法规词必须人工校对。
- 欧盟多国 listing 要分别检查语言和负责人信息。
- 日本站日语表达要符合药机法和景表法，不能直译英文。

## 上架前检查清单

- [ ] 标题无绝对化/促销/竞品词
- [ ] 五点无医疗功效/虚假认证
- [ ] 兼容性描述不暗示授权
- [ ] 图片无侵权素材/伪造标志
- [ ] 认证编号与型号一致
- [ ] 站点语言、负责人、警告语完整
- [ ] 规则检测通过或已完成人工复核
