# 受限功效词与改写手册

本手册用于把高风险宣称改写为“有依据、可验证、不涉及疾病”的表达。改写不是简单删词，必须保留真实卖点并补充证据。

## 绝对化用语

| 高风险 | 推荐改写 |
| --- | --- |
| best seller / #1 | 具体销量或排名来源，例如 `Amazon US Kitchen category top 20 (Nov 2026)`（需真实） |
| 100% guaranteed | `Backed by a 30-day return policy` |
| perfect for all skin types | `Formulated for normal to dry skin` |
| world's best / unbeatable | 具体测试结果，例如 `withstands 50 kg load in static test` |
| lowest price | 删除，或写 `price checked on 2026-11-01`（需留证） |

绝对化用语即使加了 `for some users` 也不能自动免责。平台看的是整体语义。

## 医疗与功效

普通化妆品/日用品：

- 不得写 cure、treat、prevent、heal、diagnose。
- 不得写 `FDA approved`、`medical grade`、`clinically proven`（除非有对应文件）。
- 可以写 `helps maintain`、`supports`、`cleans`、`moisturises`、`soothes`，但要避免暗示疾病。

日本站：

- `治療`、`治る`、`アレルギー`、`美白`、`育毛` 属于高风险，直接拦截。
- `抗菌`、`除菌`、`殺菌` 需要确认产品分类和试验条件。
- 化妆品可用 `肌を整える`、`うるおいを与える`。

欧盟站：

- 禁止 `anti-aging`、`repairs DNA`、`botox-like`。
- 可用 `helps reduce the appearance of fine lines`。
- 所有功效需要有产品测试或文献支持。

## 认证与检测

| 高风险 | 正确写法 |
| --- | --- |
| CE certified | `CE marked in accordance with Directive 2014/30/EU` |
| FCC certified | `Tested to FCC Part 15 Class B` |
| UL certified | `UL 1234 tested by SGS, report No. ...` |
| PSE認証 | `PSE 適合品（届出事業者：...）` |
| 食品衛生法適合 | `食品接触材料 tested to ... , report No. ...` |
| FDA approved | 仅医疗器械/药品在取得对应批准后使用，并写清编号 |

## 环保宣称

- `eco-friendly`、`environmentally friendly`：删除，或写清材料、认证和范围。
- `biodegradable`：写清测试标准（如 OECD 301B）和降解条件。
- `carbon neutral`：写清抵消范围、核算标准和第三方验证。
- `100% recyclable`：确认产品和包装都满足当地回收条件。

## 价格与促销

- `free`：写清赠品、运费或试用条件。
- `50% off`：标明原价、活动期限和最近 30 天最低价。
- `limited time`：必须有明确结束时间。
- `buy one get one`：写清赠品型号和数量。

## 改写四步法

1. 标出原句的真实卖点（材料、性能、测试、使用场景）。
2. 找到对应证据（报告、认证、专利、销量数据）。
3. 用具体名词和数字替换形容词。
4. 复查改写后是否仍暗示疾病、排名或官方背书。

## 禁止的规避手法

- 拼音、谐音、拆字、空格、符号插入。
- 图片中夹带违规词。
- 用日语/德语等小语种绕过英文规则。
- 只改标题不改五点/A+。
- 删除证据文件后继续使用宣称。
